Customer Records Tracker
Description: This is a JavaScript assignment that manages a group of customers and their purchase activity. It uses arrays and objects to store, update, and access data. 
Technologies used: JavaScript, browser console
How to Run the Project: Open the file in a code editor like VSCode. You can either run it in the terminal using node customers.js, or just paste the code into the browser console. The output can be viewed in the console.
What I learned: I increased my understanding of JavaScript. Learned how to use push, shift, and for each methods. Also learned how to retrieve specific data using .length.
